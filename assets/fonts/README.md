# Fonts

Self-hosted so the page loads nothing from third parties.

| File | Font | Used for | Licence |
|---|---|---|---|
| `funnel-display-latin-wght-normal.woff2` | Funnel Display (variable, latin subset) by NORD ID | Wordmark and headings | SIL Open Font License 1.1 |
| `funnel-sans-latin-wght-normal.woff2` | Funnel Sans (variable, latin subset) by NORD ID | Body text | SIL Open Font License 1.1 |
| `azeret-mono-latin-wght-normal.woff2` | Azeret Mono (variable, latin subset) by Displaay | Figures, prices, labels | SIL Open Font License 1.1 |

The files come from the Fontsource packages `@fontsource-variable/funnel-display@5.3.0`,
`@fontsource-variable/funnel-sans@5.3.0` and `@fontsource-variable/azeret-mono@5.3.0`.

The page deliberately avoids Inter, Space Grotesk, JetBrains Mono and IBM Plex, the faces that
generated sites fall back to, so Kaffeelisten does not look like every other template.
